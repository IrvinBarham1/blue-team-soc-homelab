# Blue Team SOC Homelab

## 🎯 Purpose

The goal of this homelab is to simulate a **small but realistic SOC** and practice:

- Collecting and aggregating logs from firewalls, servers, and endpoints  
- Detecting suspicious activity using those logs  
- Investigating events as a SOC analyst  
- Connecting hands-on work with concepts from **CompTIA CySA+ (CS0-003)**

This project documents **real evidence** from my environment and the **reasoning process** I follow to interpret it.
